# Analysis scripts

Run these from a source checkout after installing BoreTHM.

| Script | Output |
| --- | --- |
| `model1_depth_limits.py` | Circulating-temperature depth limit tables in the terminal. |
| `model1_diameter_scaling.py` | Diameter scaling tables in the terminal. |
| `model1_figures.py` | `figures/model1_profiles.png`. |
| `model2_figures.py` | `figures/model2_feasibility.png`. |
| `model3_figures.py` | `figures/model3_siting_map.png`. |
| `comparative_figure.py` | `figures/comparative_sites.png`. |
| `site_figures.py` | `figures/site_dashboard.png`. |
| `cycle_figures.py` | `figures/cycle_soultz.png` and `figures/failure_zone_soultz.png`. |
