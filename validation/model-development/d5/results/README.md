# Hydraulic comparison with the assembly correction

These are development comparisons on the frozen 16A/16B samples. The scored implementation follows D5's source-based motor and bit treatment, with PV referenced to 26.7 °C, film multiplier 1.0, cumulative exposure, 16A NC50 and 16B EIS connections. No new parameter is fitted. Historical trial insulation calibration remains disclosed.

`circulation.csv`, `run-in.csv` and `scoreboard.csv` are the unchanged scoreboard's outputs. Every planned sample remains in coverage counts. `comparison.csv` includes the approved legacy and original entry-1 results beside D5. Columns containing `paired` use identical available sample IDs for each of the three calculations. Full-population means must not be compared as if their sample sets were identical when a corrected input prevents a solve.

`bit-energy-samples.csv` includes every bit-temperature sample, with availability, bit change and the corresponding sensor-proxy change separately identified. It gives added in-hole dissipation, mass flow and reference heat capacity for comparison with the bulk heating scale. `bit-energy-assemblies.csv` summarises those paired changes. `assembly-power-return.csv` adds assembly-level power and return summaries to the frozen well-level measures. `unavailable.csv` states each unavailable circulation input.

The original bores of the BHA 23 MWD tool and BHA 38/39 PUK subs remain unknown. Their separately declared, authorised 3.25-inch thermal-only bores add no internal hydraulic loss. `initial-input-unavailable.csv` preserves the input failures before that authorisation. The completion script uses unchanged frozen functions for only those affected samples and run-in events, retains unaffected predictions and restores the complete original order before scoring. Batch source hashes and both runtimes are recorded in `manifest.json`. Every motor is qualified as **motor loss unknown**; zero additional internal motor loss is an omission pending a verified matching no-load curve. The reported-differential face heat remains unchanged. See the [component audit](../README.md) and [development log](../../../../docs/science/model-development.md) for interpretations and source qualifications.
