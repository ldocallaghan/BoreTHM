# Entry 3: cylindrical rock response

These are development comparisons on the frozen 16A and 16B samples. The calculation is the working calculation (entry 1 with D5), with the logarithmic rock term replaced by the exact constant-wall-temperature step response of a cylindrical hole. PV is referenced to 26.7 °C, the film multiplier is 1.0, exposure is cumulative with the one-hour floor, and 16A and 16B use the NC50 and EIS connection scenarios. No parameter is fitted. The historical trial insulation conductivity remains, as disclosed in the development log.

`circulation.csv`, `run-in.csv`, `scoreboard.csv` and `manifest.json` are the unchanged scoreboard's outputs from `python validation/scoreboard/scoreboard.py run --mode current`. `compare.py` then adds `comparison.csv`, which sets each scoreboard row beside the legacy baseline and the working calculation, and `assembly-changes.csv`, which gives the change in bit and return temperature from the working calculation for every sample, summarised by assembly. The manifest records the declaration and implementation commits and the source hashes, including `src/borethm/rock_response.py`.

All 467 circulation cases and all nine originally available run-in events completed, with the same sample counts as both reference calculations. The declaration, predictions and interpretation are in the [development log](../../../../docs/science/model-development.md). Source observations retain the attribution and CC BY 4.0 terms stated in the [16A](../../../forge16a/README.md) and [16B](../../../forge16b/README.md) archives.
