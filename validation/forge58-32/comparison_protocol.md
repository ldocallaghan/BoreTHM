# FORGE 58-32 pressure protocol

Registered before target access, as the second pressure well for v1.6.0. The [shared amendment](../forge56-32/protocol-amendment.md) defines settling, windows, event weighting and interval measures. Its safeguards and model/rheology variants apply here. The protocol was registered at `8bbfe2c44658dade8972a647970e3308047b6380` before implementation and target inspection or comparison.

Use only the [documented input archive](README.md) to choose windows. The source column `Pump Pressure` is the later standpipe target, with psi as the DDR convention. Input `Flow In` is US gpm; depth is ft and inlet temperature follows the source Fahrenheit convention. These unit interpretations remain visible in numerical outputs. Do not inspect PT or thermal observations.

Use the well's own component tables, survey and casing present at the time. Complete BHA descriptions identify rotary assemblies 1, 2 and 11 with no listed motor. Short bit-only descriptions on 15, 16 and 19 do not establish a complete motorless string and are excluded. Assemblies 21 and 22 occur after the pressure preparation cutoff. The remaining listed drilling BHAs carry a documented motor. No matching no-load specification has been sourced for them, so their motor-interval measure is excluded. Every status and source appears in `motor_mapping.csv`; it cannot be changed using pressure agreement.

Assign a source day only when neighbouring daily reports identify the same single BHA. This excludes assembly-transition days and missing adjacent reports. No clock offset is selected from pressure. Sampling-qualified motorless windows belong to rotary BHA 2. They are not yet a claim of complete numerical geometry or convergence. The old ten-minute windows have no unique conservative assignment. The [count table](off_bottom_counts.csv) reports old and new counts, including exclusions and separate event totals.

Numerical inputs require the remaining catalogue passage IDs/ranges and fluid-system ledger before this well's targets are accessed. Keep density and PV/YP in the same reported system, use 48.9 C as the unknown test-temperature assumption, and report 26.7 C separately. Use the same transferred FORGE formation/rock boundary assumptions as 56-32, with this well's own MD-to-TVD survey. No film multiplier, inlet value or pressure coefficient is fitted.

Report v1.5.0 and v1.6.0 standpipe residuals per window and event, in psi and percent of measured. Each event has equal weight in BHA summaries. Publish absolute and relative residuals, median/range by BHA, the pressure budget and planned/qualified/complete/converged/target-available counts. A zero target denominator gives no percentage; retain the absolute result. Missing targets, numerical failures and all exclusions remain in the evidence. No observed value or residual can remove or reassign an event.
