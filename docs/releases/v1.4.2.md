# v1.4.2: technical accuracy of model documentation

Release date: 22 October 2026. Git tag: `v1.4.2`.

## Changes

The [model guide](../science/models.md) shows the exposure-time floors already used by circulation and distinguishes them from early radial wall cooling. Its drilling-rate equations describe the spallation, assisted and mechanical branches, including the penetration-rate cap and implemented face-heat terms. It distinguishes the standalone face-heat iteration from the reference evaluation's fixed 30 kW load.

The [applicability table](../science/limitations.md#applicability-and-numerical-guards) separates accepted inputs from property-grid coverage and describes clipping, the heat-capacity path's limited extrapolation and the friction-heating pressure floor. The [API reference](../api.md#pressure-conventions) identifies absolute and gauge pressures and annotates pressure differences. Its introductory pressure section is generated from the pressure module docstring.

The [validation guide](../science/validation.md#evidence-and-independence) identifies fitted parameters and shared inputs for each comparison. It describes Newberry as a consistency check, explains the wellbore-failure evidence behind Soultz's stress bounds and limits the FORGE conservatism claim to the observed tool-temperature comparison. Existing numerical values and tables are retained. Reporting property lookups outside the grid is recorded as deferred work; no instrumentation is added.

## Calculation and data preservation

Calculations, numerical inputs and public signatures are unchanged. The changed calculation files contain docstring edits only. Source fingerprints include docstring bytes and therefore change; the fingerprint scheme and stored fingerprints are preserved.

The API generator's documentation insertion is the only executable Python change. Its remaining code is unchanged. The README, guides and summary PDF retain their v1.4.1 bytes, as do source data, benchmark records and saved results. No golden or tolerance is regenerated.
