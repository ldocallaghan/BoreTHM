# v1.4.3: benchmark dataset citation

Release date: 22 October 2026. Git tag: `v1.4.3`.

The [benchmark dataset guide](../../benchmarks/README.md#how-to-cite) and [main README](../../README.md#how-to-cite-and-data-credits) now cite the published [BoreTHM benchmark dataset, version 1.0](https://doi.org/10.5281/zenodo.23565448). The dataset manifest records the updated citation text, and the publication checklist is complete. Dataset version 1.0 is separate from software version 1.4.3.

## Verification

All 91 dataset files match the published Zenodo archive byte for byte; its archive checksum was verified. The dataset's numerical files are unchanged. All tracked Python source, dependencies and workflows retain their v1.4.2 bytes.

The local fast suite passed 404 tests in 30.75 seconds, with 106 slow tests excluded. This includes the benchmark-integrity and documentation-link tests. The link checker passed across 48 maintained Markdown files, and the API page exactly matches its generator. A full physical regression run is unnecessary for this citation and metadata patch because no calculation or numerical input changed. The v1.4.0 [complete physical-regression run](https://github.com/ldocallaghan/BoreTHM/actions/runs/39660954178) remains inherited evidence.
