# v1.4.1: documentation and reader guidance

Release date: 22 October 2026. Git tag: `v1.4.1`.

## Changes

The [README](../../README.md) distinguishes target-depth stability from fluid-density constraints over the whole hole. It introduces the project and its use without requiring development-history knowledge, and its links work from PyPI.

The scientific guides identify immediate breakout formation and the 400 °C spallation restriction as assumptions, distinguish illustrative circulation and creep cases from site programmes, and correct the explanation of supercritical water. The [summary](../guides/summary.md) and [two-page PDF](../../output/pdf/summary.pdf) include the assumed-delay opening brackets and the remaining programme failures. The PDF has a neutral filename and a visible preparation date.

The [API reference](../api.md) explains accepted ranges and provenance labels, local-helper limitations and compatibility fields. The [new-site guide](../guides/new-site.md) and [output guide](../guides/interpreting-results.md) explain inputs and a real JSON export, including pressure units, density bounds and schedule identity. Data notes correct stale descriptions and qualify equipment claims. Historical reviews remain available through the archive index.

The link checker covers the current data guides, scripts guide and changelog, and resolves absolute main-branch GitHub links against the checkout. Three added regressions check that coverage. The earlier version-specific documentation checker is labelled as historical.

## Calculation and data preservation

All 29 public exports and their signatures are unchanged. Executable statements match the reviewed baseline across all 37 package and example Python files after excluding docstrings. The calculation modules contain documentation edits only. Package fingerprints include those bytes, so cached study fingerprints can change; stored evidence and the fingerprint scheme are preserved.

All 15 source numeric data files and all 71 numerical benchmark files retain their recorded bytes. The original result, golden and historical-review records remain unchanged. The v1.4.0 release record has a dated publication follow-up.

[Benchmark dataset 1.0](../../benchmarks/README.md) remains an unpublished dataset draft with its own version. Its guide copies and provenance have been refreshed without running models or changing expected values and tolerances. It has no separate dataset DOI yet.
