# v1.3.5 release candidate: changes and verification

**Publication pending.** This candidate is based on v1.3.4 commit `1d19ac81e1de11e93ad492f876a1f5eca5a50b45`. The package metadata is 1.3.5; calculation mode and retained numerical evidence remain v1.3.4.

## Changes

The project is named BoreTHM. The README is a project guide; a documentation index separates practical guides, scientific studies and historical records. Model descriptions, validation and sources have separate pages. The output guide reflects the fields present in current reference evaluations, and the summary PDF has working source links.

The reader tables retain the selected local stability cases beside the independent programme failures. Scientific results, inputs, numerical settings and golden files are unchanged. The already-met timeline trigger and the deliberate model-development pause remain explicit in [limitations](../science/limitations.md#development-pause).

The two-page summary is a scientific outreach briefing organised around the research question, evaluated programmes, supporting evidence and questions for specialists. Its compact table shows the two deep-site counts beside the complete-programme pressure result and tool temperatures; the full case and density-bound tables remain in the README. Maintenance details and personal review status are tracked separately. PDF links now use the renamed BoreTHM repository on `main`.

The L4 base trial is selected by all settings: TK-Drakon coated pipe, 4,000 m shoe, 40/50 L/s, PV fraction 1, allowance 0.02 SG, delay 0 h, BHP null and coating rating 204 °C. Best attempted means the minimum peak in its retained schedule search. It is distinct from the reference-practice tool and coating histories.

Open target drilling intervals are counted using unrounded `drill_SG <= drill_SG_hi + 1e-9`, matching the existing diagnostic comparison. Displayed bounds use three decimal places; the verdict is copied from `cycle.cases[].verdict` and also reflects connections and the trip. It excludes the independent whole-hole, tool and equipment gates. Each site's reference thermal/hydraulic solution is reused across cases without scenario-by-scenario coupled reruns.
