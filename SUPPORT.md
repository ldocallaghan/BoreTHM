# Support

Ask questions and report problems through [GitHub issues](https://github.com/ldocallaghan/BoreTHM/issues). The [documentation guide](docs/README.md) links the installation instructions and explains how to interpret an assessment.

Include your BoreTHM and Python versions, the command or a small example, and the output you need help with. For a scientific question, state the input assumptions and the result field concerned. Remove confidential information before posting.

BoreTHM is maintained by one person. There is no guaranteed response time. See [CONTRIBUTING.md](CONTRIBUTING.md) if you would like to propose a change.
